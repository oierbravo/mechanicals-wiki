> A simple melter block that turn blocks into liquid.
> Intended for modpacks. Use as you see fit.
> Only providing basic recipes.
> Designed to work with create but it's optional.


## Version support & documentation
- 1.21.1: Supported. Documentation refers to this version.
- 1.20.1: Unsupported: [1.20.x Documentation](https://github.com/oierbravo/melter-forge-mod/tree/mc1.20.1/dev)
- 1.19.x: Unsupported: [1.19.x Documentation](https://github.com/oierbravo/melter-forge-mod/tree/mc1.19/dev) 
- 1.18.x: Unsupported: [1.18.x Documentation](https://github.com/oierbravo/melter-forge-mod/tree/mc1.18/dev)

## Heat sources.
- See JEI
- Customizable via datapack or config
- `sourceType` can be `BLOCK`, `FLUID` or `CREATIVE`
- `heatLevel` from `1` to `20` (optional, defaults to 1)
- Fluid sources decay its heat level when flowing.
